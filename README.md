
# 🤖 IA para Análise de Dados

Projeto de Inteligência Artificial focado em análise e previsão a partir de dados reais.

Este sistema permite carregar arquivos CSV, treinar modelos de Machine Learning e gerar previsões.

---

## 📌 Objetivo

Aplicar conceitos de IA em problemas práticos, transformando dados em informação útil para tomada de decisão.

---

## 🛠️ Tecnologias

- Python
- Pandas
- Scikit-learn
- Matplotlib

---

## ⚙️ Funcionalidades

- Leitura de dados
- Tratamento básico
- Treinamento de modelo
- Geração de previsões
- Visualização de resultados

---

## 🚀 Como executar

```bash
pip install -r requirements.txt
python src/treino_modelo.py
